# Student Exam Performance Prediction

An end-to-end machine learning project that predicts a student's mathematics score from demographic information, lunch type, test preparation status, reading score, and writing score.

The project includes data ingestion, preprocessing, model selection, artifact serialization, and a Flask web application for making predictions.

## How It Works

1. `src/components/data_ingestion.py` reads `notebook/data/stud.csv`, saves a copy to `artifacts/data.csv`, and creates an 80/20 train/test split in `artifacts/train.csv` and `artifacts/test.csv`.
2. `src/components/data_transformation.py` separates the target column, `math_score`, from the input features. Numeric scores are median-imputed and standardized. Categorical columns are most-frequent-imputed, one-hot encoded, and scaled.
3. `src/components/model_trainer.py` evaluates multiple regression models with `GridSearchCV` and selects the model with the highest test-set R² score. The selected model is saved as `artifacts/model.pkl`.
4. The fitted preprocessing object is saved in `artifacts/preprocessor.pkl` and is reused for new prediction inputs.
5. `app.py` serves the web interface. A submitted form is converted into a one-row pandas DataFrame, transformed with the saved preprocessor, and passed to the saved model. The predicted mathematics score is then displayed in `home.html`.

## Input Features

| Feature | Description |
| --- | --- |
| `gender` | Student gender |
| `race_ethnicity` | Race or ethnicity group |
| `parental_level_of_education` | Parent or guardian education level |
| `lunch` | Lunch program type |
| `test_preparation_course` | Whether the preparation course was completed |
| `reading_score` | Reading score from 0 to 100 |
| `writing_score` | Writing score from 0 to 100 |

The target variable is `math_score`.

## Setup

Use Python 3.8 or newer and run the following commands from the project root:

```bash
python -m venv venv
```

Activate the virtual environment:

```bash
# Windows PowerShell
.\venv\Scripts\Activate.ps1

# macOS/Linux
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

## Train the Model

Run the data ingestion module. Its `__main__` block runs ingestion, transformation, model selection, and model training in sequence:

```bash
python -m src.components.data_ingestion
```

Successful training creates or updates the following files:

```text
artifacts/data.csv
artifacts/train.csv
artifacts/test.csv
artifacts/model.pkl
artifacts/preprocessor.pkl
```

## Run the Web Application

After training, start the Flask application:

```bash
python app.py
```

Open `http://localhost:5000` in a browser and use the prediction form. The application also listens on all network interfaces because it starts with `host="0.0.0.0"`.

## Notes

- Training expects the source dataset at `notebook/data/stud.csv`.
- The model trainer rejects the result if the best test R² score is below `0.6`.
- `artifacts/`, `logs/`, and `catboost_info/` contain generated runtime output and can be regenerated by running the pipeline.
